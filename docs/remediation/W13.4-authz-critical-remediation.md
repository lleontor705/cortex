# W13 Critical Remediation

## Scope

Remediates the W13 critical findings through commit `15b3189`.

- Removed raw scoring, observation, health, backend, and transaction methods from
  the transport-visible `AuthorizedStore` method set.
- Added narrow authorized score access/update/set/access-record operations; each
  resolves the observation resource before enforcement.
- Added explicit tenant predicates to observation topic lookup, listing, counts,
  PostgreSQL search, and score/edge reads.
- Added reflection and SQL-predicate architecture tests.
- Updated tagged PostgreSQL fixtures to use a migration DSN for schema bootstrap
  and a real `NOSUPERUSER` application login for test traffic.
