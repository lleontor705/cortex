# W11.2 PostgreSQL remediation

## Scope

Remediates the PostgreSQL server repository and migration findings present
through commit `5752bb1` without changing the zero-CGO local backend.

## Changes

- Enlisted PostgreSQL repositories now detect the shared transaction in the
  context and do not commit independently. Tenant and opaque actor binding is
  performed inside that transaction; opaque subjects are persisted through the
  tenant-scoped actor mapping table rather than SQL UUID casts.
- Observation filters include project, scope, source, and type. Session APIs
  use workspace-granted public UUIDs and return public session UUIDs. Root
  counts traverse active graph descendants.
- Graph writes reject self-links, unknown relations, and invalid time ranges;
  traversal excludes deleted endpoints and remains depth bounded. Evolution
  and contradiction queries use their destination/time predicates.
- The outbox schema and repository now track causes, errors, affected rows,
  completion time, lease owner/expiry, and recover only expired leases.
- The server migration adds the required columns, actor mapping, constraints,
  recovery index, forced RLS coverage, and an explicit checksum-verified
  rollback path.
