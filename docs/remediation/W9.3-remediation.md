## Remediated invariants

1. v2 runtime tests cover temporal closure/history, rollback boundaries,
   concurrent supersedes, tenant/project/workspace isolation, Unicode
   canonicalization and collision resistance, bounded traversal/cycles, and
   valid/system-time `AsOf` traversal.
2. v2 supersede/contradict writes reject autocommit. Predecessor closure and
   successor insertion execute on the same enlisted `*sql.Tx`; transaction
   failure leaves zero committed partial state.
3. Closure matches exact `from_obs_id`, `to_obs_id`, relation, tenant, and
   workspace. It no longer closes every fact sharing only a target.
4. v2 current facts use a partial unique index over target/relation/tenant/
   workspace. SQLite serializes the write conflict; one concurrent successor
   commits and the losing request returns a conflict/lock error without closing
   unrelated state.
5. Entity storage implements `TxParticipant`; `SaveLinksInTx` reuses the
   shared transaction. Observation, outbox, and extracted entity links are
   enlisted together by the bundle save path. Scoped lookup filters tenant,
   workspace, and project through the owning observation.
6. Every recursive traversal hop applies valid-time and transaction-time
   predicates when `AsOf` is set.
7. Domain and storage use `domain/entity.Normalize`, including NFKC Unicode
   normalization and separator-preserving collision resistance.
8. Traversal uses an ID path visited set plus depth and budget limits; cycles
   cannot expand recursively without bound.
