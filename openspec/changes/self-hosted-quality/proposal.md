# Proposal: Self-Hosted Quality

**Change ID:** self-hosted-quality | **Workflow:** sdd-full | **Spec plane:** hybrid | **Board:** self-hosted-quality | **Workload policy:** flexible

## Why

Three completed investigations plus a fourth (post-pivot architecture review, ses_f16c72d96) converge on the same conclusion: the self-hosted pivot and embedded-web redesign landed their code, but the quality surface around them did not keep pace.

- **Docs/CLI/TUI (Cortex obs 711):** documentation staleness is HIGH across `docs/INSTALLATION.md:57-66,70,90-97,300`, `docs/SERVER.md:9,15,19`, and `docs/RAILWAY_DEPLOYMENT.md:20,39,53,74,76,127` (retired `cortex-web` image, `:3000`, `NEXT_PUBLIC_*`); MED across the verification matrix (`:3000` gate vs actual `:7438`), capability matrix (CLI/TUI rows), `docs/README.md` index (8 missing entries + dead `docs/remediation/` pointer), ARCHITECTURE/CONFIGURATION/GRAPH_INTELLIGENCE profiles, and two Multi-Tenant-labelled SVGs. `web key`, `backup`, `update`, `ingest`, `watch`, `code` (9 subcommands / 15 flags), exit codes, `--mode server`, and the environment-variable matrix are entirely undocumented, and **no TUI document exists** for the 15 screens + 5 overlays the product ships.
- **Security:** a hardcoded `GrantVersion: 1` (`internal/platform/server/static_verifier.go:70`) contradicts the migration-112 static MAC computed at the database's real grant_version, producing a latent, non-recoverable HTTP 28000 outage on any canonical-grant reconcile. Alongside it sit an auth-logout no-op on YAML (`internal/cli/cli.go:2223` + `mergeYAMLNode`), an empty-host loopback bypass (`internal/cli/cli.go:1430-1434`), compose defaults that contradict the distinct-role boundary, an unfiltered BFS expansion that discloses out-of-project observations (`internal/http/parity_graph.go:159-174`), and untracked credential-capable Playwright artifacts.
- **Performance:** the ranked top-10 identifies a 30-60% p50 server win (per-request audit+bind transaction), a 500->2 MCP graph N+1, a two-phase vector search, and five quick wins, all currently unmeasured: no baseline is recorded, and five benchmark oracles do not exist.
- **Architecture (fourth audit):** 122 dirty git paths (51 modified / 65 untracked / 6 deleted) span both landed initiatives and are **uncommitted**, which makes every subsequent diff unreviewable; a length oracle in `subtle.ConstantTimeCompare` over raw bearer bytes (LOW-9), a 401-envelope and X-API-Key/trim policy divergence between `internal/http.withAuth` and `platform/server` requestAuthenticator (debt #13), three literal copies of the synthetic principal (debt #14), and coverage documentation that still claims a 70% CI threshold while `ci.yml:199` enforces 80.0 (debt #15).

## Risks

- **Uncommitted baseline:** committing 122 paths must precede every task or diffs become unreviewable; risk of a monolithic commit is mitigated by three logical commits and `git status --porcelain` as the exit oracle. No destructive git operation is allowed at any point.
- **HIGH-1 outage window:** the grant-version fix is the most dangerous finding; if it lands incorrectly the server fails closed at startup (preferred) or returns 28000 (not preferred). Mitigation: startup equality assertion plus a unit case at `grant_version=2`, sequenced first in the security wave.
- **Bearer unification regressions:** unifying trim/X-API-Key/401 envelope touches two auth paths with many literal-based tests. Mitigation: `requestAuthenticator` struct fields stay unchanged, the primitive is adopted behind existing seams, `internal/http/server_test.go` and `platform/server/authentication_test.go` remain the oracles, and `npm --prefix web run test` guards the web 401 contract.
- **Compose default flip:** flipping `CORTEX_SERVER_BOOTSTRAP_DEVELOPMENT` to false changes the docker stack's bootstrap path (e2e inherits the default). Mitigation: a Go contract test asserts both compose files default to false; CI `docker-compose-smoke` and `docker_e2e` remain the authoritative executors and are reported BLOCKED locally when Docker is absent.
- **Document accuracy:** two large new documents can drift immediately. Mitigation: both are pinned indirectly by the docs gate (`go test -v -count=1 ./bench`) and by capability/verification matrix rows written in the same change; reviewers anchor every flag to `cortex help` output.
- **Sequential same-file contention:** `cli.go` (3 tasks), `static_verifier.go` (3 tasks), `parity_graph.go`, `parity_ops.go`, `tools_cortex.go`, `AGENTS.md`, `compose_defaults_test.go` are each touched more than once; dependency edges serialize them, parallel writers stay file-disjoint, and the orchestrator dispatches at most 3 concurrent writers.
